# Jornada Viagens ✈️

Projeto de um site responsivo para uma agência de viagens fictícia, desenvolvido como prática de desenvolvimento Front-end durante os estudos na Alura.

## 🌎 Sobre o projeto

O Jornada Viagens apresenta uma página de agência de viagens com ofertas, categorias de serviços, destinos populares, condições de pagamento e depoimentos de clientes.

O projeto foi desenvolvido com foco na construção de interfaces responsivas, organização de código e implementação de interações com JavaScript.

## 🚀 Funcionalidades

* Menu de navegação interativo.
* Seção de ofertas da semana.
* Apresentação de categorias de serviços.
* Exibição de destinos populares.
* Seção de condições de pagamento.
* Área de depoimentos de clientes.
* Layout adaptável para dispositivos móveis e desktops.

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
